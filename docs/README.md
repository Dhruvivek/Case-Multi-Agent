# Project Documentation

This directory holds durable project knowledge rather than generated output.

- `project-brief/`: assignment brief and source material.
- `reference-material/`: provided reference files.
- `specs-planned/`: active or planned product/design specifications.
- `specs-implemented/`: shipped or superseded specifications.
- `adr/`: architecture decisions with lasting trade-offs.
- `qna/`: resolved design questions worth retaining.
- `templates/`: reusable document templates.
- `agents/`: local conventions for people and coding agents.
